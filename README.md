# MATLAB-Data-Visualization

Data Visualization Tool Using MATLAB
Task 3 — Data Visualization

A simple MATLAB GUI application that allows users to visualize numerical data using line plots, histograms, and scatter plots.

Problem Description

Data visualization is an important part of data analysis because it allows information to be understood more easily through graphs and charts.

This project creates a simple MATLAB tool where the user enters X and Y values and selects one of three visualization options:

Line Plot
Histogram
Scatter Plot

The project uses student marks as a simple example dataset.

Technology Used
MATLAB
MATLAB plotting functions
MATLAB GUI components

Features
Simple graphical user interface
User-defined X and Y data
Line plot generation
Histogram generation
Scatter plot generation
